# A5-1 記憶閃回：設計（定稿）

> 狀態：**定稿**（Claude 2026-10-14 起草，作者同日確認：效果用 A、B 當備案；scene_19 繼續用〔之後也可以做新的素材〕；4 個物品照原案；閃回音由 Claude 合成候選、另外整理免費素材）。這一個互動**不需要新的劇情文字**（沿用現有的調查文字），只要決定畫面、對應的插畫與聲音。
> 預覽：`art/design/a5/flashback/compare_scene_10.png`、`compare_scene_05.png`（原圖／A／B）、`zoom_scene_*.png`（放大看雜訊）、`flashback_timing.gif`（轉場節奏，用 A 示範）。

## 1. 玩起來的樣子

調查關鍵物品時，主角伸手（A3 的動作）之後：

1. 畫面**白光一閃**（0.2 秒），同時響起閃回音。
2. 切到原本的第一人稱插畫，加上褪色、雜訊（每格跳動）、暗角，**停約 2.2 秒**。
3. 淡出到黑（0.3 秒），回到區域（0.3 秒）。
4. 顯示原本的調查文字。

- 整段約 3 秒；閃回中**按互動鍵可以跳過**（直接回到區域、顯示文字）。
- **每個物品一輪只閃回一次**；再調查時直接顯示文字。
- 閃回不加數值（調查本身原本的數值照舊）。

## 2. 哪些物品、配哪張插畫

只用還沒當過遠景、過場的插畫，避免重複（`scene_19` 例外，見下方說明）。

| 物品 | 調查內容 | 閃回插畫 |
|---|---|---|
| 停車場：醒來的地方 | 口袋裡和小女孩的合照 | `scene_19`（一家人在餐桌旁笑著） |
| 診所：診療椅（有錄音筆時） | 錄音筆裡女兒的聲音 | `scene_05`（手裡的錄音筆） |
| 設施走廊：實驗紀錄 | 「受試者：楊尚瑜，編號 07」 | `scene_12`（手術台、SUBJECT: SILENT） |
| 舊家：牆上的蠟筆字 | 「爸爸，我知道是你」 | `scene_10`（牆上發光的 DADDY, I KNOW THAT'S YOU） |

> **`scene_19` 也是結局 B（偽記憶回圈）的畫面**。在開頭當成「真的記憶」出現，到結局 B 再看到同一張，可以當作呼應；如果覺得會破壞結局 B，改用 `scene_11`（暗處手握錄音筆）或不給「醒來的地方」閃回。
> 其他可以考慮的：街道的尋人啟事、診所的治療室（沒有很貼切的插畫，這一版先不做）。

## 3. 畫面效果（作者選 A，B 當備案）

| | A：褪色＋輕微雜訊（建議） | B：舊底片 |
|---|---|---|
| 顏色 | 飽和度降到約 35%，保留一點原本的暖色 | 幾乎黑白，帶一點棕色 |
| 雜訊 | 輕微、每格跳動 | 明顯的顆粒＋掃描線 |
| 其他 | 暗角 | 紅色往右偏 2px（色偏）、暗角 |
| 感覺 | 模糊的回憶，畫面還看得清楚 | 很舊的錄影，比較「恐怖片」 |

實作用一個 shader（`shaders/flashback.gdshader`），強度參數放在屬性面板，之後可以微調。

## 4. 聲音（閃回音 E6）

`docs/A+素材提示詞.md` 的 E6：*soft reversed piano swell with tape warble and faint static*（反轉的鋼琴漸強、錄音帶的音高晃動、微弱雜音），1.5～2.5 秒。

| 方式 | 說明 |
|---|---|
| **Claude 合成（建議先試）** | 從現有的音樂（例如標題曲的鋼琴）取 2 秒反轉、加音高晃動與雜音，做 2～3 個候選放進試聽網頁 |
| 作者找免費素材 | Freesound 搜 `reverse piano swell`、`tape rewind`、`memory flashback` |

## 5. 資料格式

```json
"wall": {
  "type": "inspect", "title": "牆上的蠟筆字", ...,
  "flashback": "scene_10.webp"
}
```

- 互動點或 variant 加 `"flashback": "插畫檔名"`（`assets/bg/`）。診療椅寫在「有錄音筆」的 variant 裡，沒有錄音筆時不閃回。
- 劇本檢查：插畫檔案要存在；只能用在調查類（inspect、item、choice 的開頭）。
- 已經閃回過記在旗標「區域.互動點.flashback」。
