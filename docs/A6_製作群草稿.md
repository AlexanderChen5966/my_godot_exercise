# A6-2 製作群（定稿）

> 狀態：**定稿**（作者 2026-10-16）：作者名稱與「開發協助：Claude」**先不加**；CC0／Pixabay 的感謝名單**保留**；其餘照草稿。寫在 `data/credits.json`，Godot 授權聲明由引擎提供（`Engine.get_license_text()`、第三方元件清單）。來源整理自 `docs/素材來源.md`。【】是要作者填或決定的地方。
> 畫面：標題選單的「製作群」打開一個和設定一樣的面板，內容可以上下捲動（↑↓ 或滑鼠滾輪），Esc／返回關閉。

## 必須標示的部分

| 項目 | 原因 |
|---|---|
| **CC BY 素材的作者**：cosmicembers、pfranzen、Metris | CC BY 授權要求標示作者、作品名稱、授權 |
| **Godot Engine 的授權聲明**（MIT） | Godot 官方要求發布的遊戲附上引擎的授權文字（建議放在製作群畫面） |
| 字型 Noto Sans TC（SIL OFL 1.1） | 不強制標示，但慣例會列出 |

CC0 和 Pixabay 授權不需要標示，草稿裡用「感謝」的方式列出，作者可以決定要不要保留。
