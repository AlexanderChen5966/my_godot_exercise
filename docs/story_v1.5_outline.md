## 1. 區域與過場

每個互動點的類型：
- **inspect（調查）**：走過去按互動鍵，顯示一段文字。有些會加數值。
- **approach（接近）**：走到附近**自動觸發**，用在遇到人的時候（衝動機制在 Lv5 加入）。
- **choice（選擇）**：顯示文字＋選項，選了才有後果。**新的類型**。
- **item（物品）**：撿起後會記住，之後的事件會不同。**新的類型**。
- **exit（出口）**：通往下一個區域或過場。

## 2. 數值

| 數值 | 初始值 | 意義 |
|---|---|---|
| 記憶 | 0 | 調查線索、面對過去會增加 |
| 人性 | 3 | 壓抑衝動會增加，屈服於衝動會減少 |

### 記憶的來源（最多 9）

| 地點 | 來源 |
|---|---|
| 停車場 | 口袋裡的照片 |
| 街道 | 尋人啟事 |
| 診所 | 治療室的字卡、錄音筆（播放或呼喊） |
| 手術台 | 環顧或聆聽（二選一） |
| 設施走廊 | 收下筆記本 |
| 廢墟 | 隔著圍籬看著妻子 |
| 舊家 | 牆上的字、對女兒比手勢 |

### 試算

| 路線 | 做法 | 記憶 | 人性 | 能選的結局 |
|---|---|---|---|---|
| 最佳 | 每個地方都調查，每次都壓抑衝動 | 9 | 3+1+1+2+1+1 = 9（避難所選「看著她」時 8） | A、B、C |
| 一般 | 只調查一半、偶爾失控 | 4～5 | 2～4 | B、C |
| 直衝 | 不調查，直接走出口 | 0～2 | 3 左右 | 只有 C |
| 失控 | 撲向婦人、摔碎錄音筆、加入同類、撲向科學家 | 視調查而定 | 3−1−1−2−2 = **−3** | 記憶夠也進不了 A |

- 想拿到結局 A，至少要調查 9 個記憶來源中的 6 個，而且不能太常失控。
- **待決定**：人性降到 0 以下時，要不要另外觸發「☠ BE4 失控」？（見第 5 節）

## 6. 之後的步驟

1. 作者審這份大綱（可以直接在檔案裡改，或告訴 Claude 要改哪裡）。
2. Claude 依定稿大綱寫 `docs/story_v1.5_draft.md`：每個互動點的完整文字。

4. 定稿後：寫入 `data/story.json`、`data/areas/*.json`（舊版備份到 `docs/story_v1.0.json`），並寫 `docs/asset_requests.md`（新區域的背景、BGM、音效、像素道具的需求與提示詞）。
