## 1. A＋要達成什麼

把現在「一張插畫當遠景＋色塊與像素物件＋2D 燈光」的畫面，做成**有層次、會動、有聲音**的 2.5D，並加入新的互動方式。內容來自作者在 Lv6 試玩後列出的「下一版想做的」：

| 作者的想法 | 對應的等級 |
|---|---|
| 場景（更多背景細節） | A1 分層背景、A2 光影與空氣感 |
| 會動的像素 | A3 |
| 音效 | A4 |
| 互動方式 | A5 |
| 小項目（醒來處的血跡還是色塊、物件可再改進） | A1／A3 順便處理 |
| 網頁版太大（88MB） | A6 |

> **聲音素材的原則（作者 2026-10-08 決定）**：本專案是實驗用、**沒有商業用途**，所以授權只要允許個人／非商業使用即可（例如 CC-BY-NC、BBC Sound Effects 也可以用），**以「找到適合的聲音」為最優先**。每個外部素材仍要記錄來源與授權（`docs/素材來源.md`），需要標示作者的素材在遊戲或發布頁面標示。

## 3. 使用的 MCP

| MCP | 用途 | 狀態 |
|---|---|---|
| godot-mcp-toolkit | 建場景、節點、燈光、粒子、shader、驗證 | 已在用 |
| pixelorama | 像素剪影、地面、動畫 | 已在用 |
| **ElevenLabs MCP**（官方，`elevenlabs/elevenlabs-mcp`） | **只用來補缺**：免費素材找不到合適的聲音時，用 `text_to_sound_effects`／`compose_music` 產生 | **A4 視需要新增**。需要 ElevenLabs 帳號與 API key，**每次呼叫會消耗點數**；只在作者同意時呼叫。也可以完全不用 |

音樂與音效都以免費素材為主。補缺時：Suno 沒有官方的 MCP，所以由作者在 Suno 網站貼提示詞產生；也可以改用 ElevenLabs 的 `compose_music`。

## 5. 每一級的內容

### A1：分層背景

**目標**：每個區域從「一張插畫＋色塊」變成**遠景、中景、遊戲層、近景、前景**五層，走動時明顯有前後景深。

| 層 | 視差倍率（參考） | 內容 | 誰做 |
|---|---|---|---|
| 遠景 Far | 0.2～0.3 | 側面全景插畫（天空、遠處建築） | 外部 AI |
| 中景 Mid | 0.5～0.7 | 中距離的剪影（柱子、廢車、樹、建築輪廓），半透明或偏暗 | Claude |
| 遊戲層 | 1.0 | 主角、人物、互動物件、像素地面 | 現有＋Claude |
| 近景 Near（新增） | 1.0，排在主角前面 | 地上的小東西（碎石、紙張、草） | Claude |
| 前景 Front | 1.2～1.4 | 靠近鏡頭、很暗的剪影（柱子、鐵絲網、樹枝） | Claude |

步驟：
1. **A1-0 規格**：決定每層的倍率、明暗、遠景的畫面重點位置；先做**停車場**一個區域當樣板。
2. **A1-1 停車場**：換遠景（作者還沒交付就先用現有 `scene_01` 但調整構圖）、Claude 畫中景與前景剪影、像素地面、醒來處的血跡畫成像素。截圖給作者確認層次。
3. **A1-2～A1-7**：其餘 6 個區域，一區一確認。
4. 每一區都要確認：互動物件與人物沒有被前景擋住、對話框區域的可讀性。

驗證：在區域起點、中段、終點截圖比較各層位移是否符合倍率；`runtime_get_node_state` 讀各層位置。

完成標準：
- [ ] 7 個區域都有五層，走動時有明顯景深
- [ ] 互動物件、人物不被擋住，提示與對話框看得清楚
- [ ] 網頁版流暢（作者主觀確認，Claude 回報 FPS）

### A1.5：上下左右移動（縱深帶）

> 2026-10-08 作者決定：做成像《小朋友齊打交 2》那樣**可以上下左右走**，只要移動和調查物品，**不跳躍**；必要時人物可以做新的動作。順序：**A1-1 停車場完成 → A1.5 → A1-2～A1-7**（地面高度與近景規則會改變，所以要在其他 6 區之前做）。

**目標**：地面從「一條線」變成「有深度的帶狀區域」。按上下鍵是往畫面裡面／外面走（不是跳），人物和物件依腳的位置自動決定前後。

| 項目 | 規格（A1.5-0 再和作者確認數值） |
|---|---|
| 縱深帶 | 腳的 y 範圍約 **640～740**（深 100）；每個區域可以在 `area.gd` 的屬性面板調整上下界 |
| 移動 | 上下左右（新增動作 `move_up`／`move_down`：方向鍵上下、W／S），**上下速度約左右的 0.6 倍**；斜走時速度正規化 |
| 動畫 | 沿用現有左右走路動畫（上下走時播目前面向的走路動畫，《小朋友齊打交 2》也是這樣）。新動作（例如調查時伸手）照 A3 的做法，需要時再畫 |
| 前後排序 | 主角、人物、互動物件、近景物件放進同一個 **y 排序**（`y_sort_enabled`）的節點，原點都放在腳底／物件底部 |
| 深度縮放（選做） | 越裡面越小，例如最裡面 0.92 倍；A1.5-0 用 A／B 截圖給作者選 |
| 影子 | 主角與人物腳下加半透明橢圓影子，玩家才看得出站在哪個深度 |
| 互動 | 互動範圍加上深度：要走到物件前面（深度差在約 ±40 內）才會出現提示 |
| 阻擋（選做） | 大物件（例如燒毀的車）不能穿過；先不做，試玩後再決定 |
| 鏡頭 | 上下不動（畫面高度固定 768），只跟著左右 |
| 區域資料 | `spawns` 可以寫 `x` 或 `[x, y]`（只寫 x 時站在縱深帶中間）；劇本檢查認得新格式、檢查 y 在縱深帶內 |
| 近景 | 改成參與 y 排序的地面物件；放在縱深帶最下面（y 750 以下）的仍然永遠在最前面 |

步驟：
1. **A1.5-0 規格**：在停車場用 A／B 截圖決定縱深帶的範圍、要不要深度縮放；確認對話框與提示文字的位置不被擋住。
2. **A1.5-1 移動與影子**：`player.gd` 加上下移動、縱深帶限制、影子；`project.godot` 新增 `move_up`／`move_down`（用 Toolkit 的 input_map 工具）。
3. **A1.5-2 前後排序與互動**：停車場改成 y 排序的結構；互動點加深度判定；`spawns` 支援 y。
4. **A1.5-3 套用到其他 6 區**：只調整結構與縱深帶（畫面在 A1-2～A1-7 再做），確認每一區都能從頭玩到結局。
5. **A1.5-4 測試**：`tests/play_base.gd` 的 `walk_to` 支援 y；新增 `tests/test_a15.gd`（上下移動與邊界、前後排序、從不同深度互動、影子跟隨）；舊的 77 項全部通過。

驗證：`input_simulate` 送上下鍵、讀主角座標與排序結果；在縱深帶上緣、下緣各截圖，確認主角走到物件前面／後面時遮擋正確。

完成標準：
- [ ] 7 個區域都能上下左右走，不能走出縱深帶
- [ ] 前後遮擋正確，影子跟著主角
- [ ] 互動要站到物件前面才會觸發，所有劇情、結局照常走得到
- [ ] 舊測試＋A1.5 新測試全部通過
- [ ] 作者試玩確認手感

### A2：光影與空氣感

| 項目 | 做法 |
|---|---|
| 陰影 | 柱子、車體、門框加 `LightOccluder2D`，被手電筒與火光照出影子（Lv2 跳過的部分） |
| 法線貼圖 | 主角與人物加法線貼圖（`CanvasTexture`），燈光從側面照時有立體感。**A2-1 先在網頁版確認效果與效能**，不划算就只用在主角 |
| 粒子 | `CPUParticles2D`（網頁版較穩）：手電筒光裡的灰塵、街道與走廊的火星、廢墟飄落的灰燼 |
| 霧 | 中景與遊戲層之間一層緩慢流動的霧（noise shader，低透明度） |
| 光束 | 診所的窗光、舊家屋頂破洞、牆前的光：疊加模式的光束 sprite 或 shader |
| 鏡頭 | 事件發生時輕微推近、槍聲與撲上去時震動；衝動強度高時輕微晃動 |

驗證：每項做 A／B 兩種強度截圖給作者選（Lv2 證明這個方法最有效）；回報網頁版 FPS。

完成標準：
- [ ] 每個區域至少有一種空氣感效果（灰塵、火星、灰燼、霧或光束）
- [ ] 陰影與法線貼圖在網頁版正常、流暢
- [ ] 效果不影響文字閱讀

### A4：聲音

| 類別 | 內容 |
|---|---|
| 腳步 | 跟行走畫格同步（腳著地的那兩格）；地面材質：水泥、碎玻璃、木地板（舊家） |
| 互動音 | 調查（翻找）、撿起物品（取代暫用）、開門、選項游標移動與確認 |
| 事件音 | 低吼（撲上去）、槍聲（BE1）、撞鐵絲網（BE3）、新心跳聲（取代 `sound_generate` 的暫用） |
| 環境音 | 每個區域一條循環：停車場滴水＋低頻嗡聲、街道風聲＋火聲、診所遠處鳥叫與風、走廊警報、廢墟遠處的低吼與避難所的人聲、舊家木頭吱嘎聲、牆前幾乎無聲的耳鳴 |
| 位置音效 | 火、警報、避難所用 `AudioStreamPlayer2D`，走近變大聲、左右聲道隨位置改變 |
| 背景音樂 | Bad End 專用、避難所（v1.5 素材清單的 M1、M2），可選新的標題曲 |
| 音量分組 | Audio Bus：Master／BGM／SFX／Ambient，讓 A6 的音量設定可以分開調 |

流程：
1. **A4-0**：Claude 依 `docs/A+素材提示詞.md` 第 3 節，為每個音效列出**搜尋關鍵字與建議的網站**（可以的話附上候選素材的網址）。
2. **A4-1**：作者下載免費素材，放在專案外的暫存資料夾（例如 `~/Desktop/失語者_sfx候選/`），每種可以多放幾個候選。
3. **A4-1b（補缺）**：找不到合適的音效或音樂，作者決定是否用 ElevenLabs（安裝 MCP、定點數上限）或 Suno；AI 產生的候選同樣先放暫存資料夾。
4. **A4-1c**：Claude 整理候選：轉 ogg、裁切、音量一致化、環境音接成無縫循環；作者聽過挑選後才放進 `assets/sfx/`（音樂放 `assets/bgm/`），並寫進 `docs/素材來源.md`。
5. **A4-2**：程式接上（腳步同步、環境音循環、位置音效、Bus）。
6. **A4-3**：作者試聽整輪，調整音量平衡。

> Claude 聽不到聲音，所以 A4 的驗證以「有在正確時機播放」為主（讀播放狀態、log），**好不好聽完全由作者判斷**。

完成標準：
- [ ] 腳步、互動、事件、環境音都有，時機正確
- [ ] 位置音效隨距離變化

### A5：新的互動方式

A5-0 由作者從下面挑 1～2 個（建議先做 1 和 2，風險低、和劇情最貼）：

| # | 互動 | 說明 | 規模 |
|---|---|---|---|
| 1 | **手勢** | 按 G 比出手勢。主角唯一的溝通方式，呼應營火故事裡「比著奇怪手勢的噬語者」。部分人物（女兒、女科學家）對手勢有反應，可能增加記憶或人性 | 小 |
| 2 | **記憶閃回** | 調查關鍵物品（照片、錄音筆、蠟筆字）時，畫面短暫切到原本的插畫（20 張第一人稱圖）加上雜訊與褪色效果，再回到區域。重新利用原本的素材 | 小 |
| 3 | **壓抑衝動** | 衝動強度達到最高時，按住一個鍵抵抗；成功人性 +1，失敗就撲上去 | 中 |
| 4 | **躲藏** | 在設施走廊躲進陰影或物件後面，避開警衛的手電筒（A3 的掃動） | 中～大 |

每個互動都要：擴充 `data/areas/*.json` 格式 → 劇本檢查認得新欄位（並用故意寫錯的資料測試）→ 遊玩測試新增項目 → 新文字由 Claude 起草、作者定稿。

完成標準：

- [ ] 三個結局與三個 Bad End 仍然都走得到（劇本檢查窮舉）
