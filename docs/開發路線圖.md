## 1. 原本的規劃（階段 1～4）

最早的規劃是以「遊戲內容」來分階段：

| 階段 | 內容 | 狀態 |
|---|---|---|
| 1 | 視覺小說式：背景＋文字＋選項＋背景音樂 | ✅ 2026-10-02 完成（見 `MCP實驗紀錄.md`） |
| 2 | 像素立繪、表情差分、簡單過場動畫 | 併入新路線（見下方） |
| 3 | 可走動的 2D 地圖，走到特定位置觸發劇情，沿用階段 1 的資料 | 併入新路線 |
| 4 | 2.5D 或 HD-2D 的視覺處理 | 併入新路線 |

## 2. 為什麼改成新路線（Lv1～5）

1. **目的改變**：重點是練習 MCP 和 AI 輔助開發，所以改成「每一級多練一種 MCP 用法」，由簡單到難。
2. **確定做成 2.5D、可移動**：原階段 3、4 變成主線，往前提。
3. **原階段 2 的「立繪＋表情差分」暫時不做**：劇本是第二人稱旁白，主角不能說話，出場人物多半只出現一次，立繪能發揮的地方很少。
   原階段 2 中適合這份劇本的部分（物品特寫、畫面特效）可以隨時插進任何一級。

> 簡單說：原本的「階段」以**遊戲內容**來分，新的「Lv」以**練習的 MCP 技能**來分。

## 3. 新路線

| 順序 | 等級 | 內容 | 練習重點 | 新增的 MCP | 對應原本的 |
|---|---|---|---|---|---|
| 1 | **Lv1** | 停車場（原場景 1～2）可左右走動、3 個互動點、出口接回視覺小說；替代美術 | 用 MCP 建 2D 場景與角色；用模擬按鍵＋讀座標讓 Claude **自己驗證移動與觸發** | — | 階段 3（一個區域） |
| 2 | **Lv2** | 停車場加上景深分層（視差）與光影 | AI 對「氛圍」這類主觀要求能做到多好 | — | 階段 4（形式 A） |
| 3 | **Lv3** | 用像素工具 MCP 畫主角（待機＋行走動畫） | **第二個 MCP**：AI 畫像素圖的品質、兩個 MCP 能否配合 | **Pixelorama MCP** | 階段 2 的像素美術 |
| 4 | 劇本 v1.5 | 把劇本改寫成「區域 × 事件」格式；同時處理重複劇情 | AI 協助劇本設計（Claude 起草、作者審稿） | — | — |
| 5 | **Lv4** | 增加街道、診所兩個區域，加入物品與旗標 | 多場景切換、全域狀態；專案變大後 AI 能否維持品質 | （Aseprite MCP，選做） | 階段 3 擴大 |
| 6 | **Lv5** | 記憶／人性數值、衝動機制、Bad End、依數值決定結局 | AI 協助遊戲機制與平衡 | — | v1.5 規劃的內容 |
| — | 挑戰 | HD-2D（3D 場景＋像素角色） | Godot 3D、Blender MCP | Blender MCP | 階段 4 高難度版 |

**每一級做完都有一個可以從頭玩到結局的成品**（可移動的區域接回原本的視覺小說流程），任何一級都可以停下來。

## 4. 已確定的決策

| 議題 | 決定 | 日期 |
|---|---|---|
| 2.5D 形式 | **形式 A：橫向捲軸＋景深分層**（參考 Inside、Limbo）。不做 HD-2D，留作挑戰 | 2026-10-02 |
| Godot MCP | **Godot MCP Toolkit**（編輯器外掛）。Coding-Solo/godot-mcp 已停用 | 2026-10-02 |
| 像素工具 MCP | **先用 Pixelorama MCP**（免費，Lv3 開始）。流程確認沒問題後，再購買 Aseprite 練習 Aseprite MCP | 2026-10-02 |
| 劇本 v1.5 | **暫停**，等 Lv3 完成後改寫成「區域 × 事件」格式再開始。原規劃見 `docs/v1.5_劇本調整規劃.md` | 2026-10-02 |
| 一次只加一個新 MCP | 是。方便判斷每個 MCP 的效果，出問題時也容易找原因 | 2026-10-02 |
| 美術 | Lv1、Lv2 用替代美術（色塊＋現有插畫），Lv3 才開始畫像素角色 | 2026-10-02 |
| 手機 | **Lv1 起暫不支援手機**：可走動區域只有鍵盤操作；直式畫面顯示橫向持握提示。觸控操作之後再評估 | 2026-10-02 |
| 用詞統一 | 主角名稱「**楊尚瑜**」；保有意識的感染者「**靜語者**」（場景 15 的「噬語者」已改正） | 2026-10-02 |
| Web 匯出資料 | 遊戲需要的資料一個都不能少：`include_filter` 改為 `data/*.json, data/areas/*.json`，之後新增資料資料夾時要一併加入，並在匯出後檢查 `.pck` 內容 | 2026-10-02 |

| Lv5 | ✅ | ✅ | 依 Lv4 的比較結果決定 |

### Pixelorama MCP 備忘（Lv3 時使用）

- 專案：<https://github.com/abidoo22/pixelorama-mcp>（MIT，2026 年 5 月開始、作者一人，約 97 個工具）
- 文件寫明對應 **Pixelorama v1.1.10**，請安裝這個版本，暫時不要升級 Pixelorama。
- 只安裝擴充功能 `PixMcpBridge.pck`。專案根目錄另有一個用途不明的 `Pixelorama.pck`，**不要用它取代你的 Pixelorama**。
- 擴充功能只監聽本機 `127.0.0.1:7373`，沒有驗證機制；不用時關掉 Pixelorama 即可。
- 如果不穩定（畫壞、連線斷掉），改用 Aseprite MCP。兩者都輸出 PNG／spritesheet，Godot 端幾乎不用改。
