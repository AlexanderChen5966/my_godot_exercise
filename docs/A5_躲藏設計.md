# A5-1 躲藏：設計（定稿）

> 狀態：**定稿**（作者 2026-10-16）：第 3 節四項都做 **A**，**B 都當之後的升級方案**（警衛巡邏走路、主角蹲下動畫、被發現直接 Bad End、通風管只當掩護）；第 4 節文字定稿。
> 示意圖：`art/design/a5/hide/layout.png`（設施走廊的配置與路線）。

## 1. 想法

現在的設施走廊：走近警衛就**一定**觸發警衛事件（抵抗衝動 → 躲進通風管／撲向警衛／停下不動）。
躲藏讓玩家**可以靠自己避開警衛**：利用掩護躲過手電筒的光，鑽進通風管，從出口那一側爬出來，不用和警衛正面遇上。
被光照到也不是 Game Over，而是進入原本的警衛事件，所以失敗的代價不會太重。

## 2. 玩起來的樣子

1. 走過女科學家之後，第一次進入警衛附近，畫面下方淡淡顯示一次：「避開手電筒的光：靠近掩護按 E 躲起來」。
2. **警衛不再只是站著**：面向左（照向主角這一側）約 4 秒、轉身面向右約 3 秒，一直交替；手電筒照著時光錐上下掃（A3 的搜索動作）。
3. **被照到**：主角不在掩護裡、身體在光錐裡超過 0.4 秒 → 警衛發現你（轉向你、舉槍瞄準、槍上膛的聲音、畫面震動）→ 進入原本的警衛事件（抵抗衝動 → 選項），文字換成「被發現」的版本。
4. **掩護**：走到掩護前面會出現「E　躲起來」，按 E 主角躲到後面（畫面上變暗、半透明），光照到也不會被發現；再按 E 或移動就出來。
   - 推車（x 950，已經有）
   - 新：箱子（x 1270）
   - 新：通風管入口（x 1450，在光錐範圍內，要趁警衛轉身面向右時才過得去）
5. **鑽進通風管**：在通風管入口按 E → 顯示原本「躲進通風管」的回應文字 → 黑畫面 → 從通風管出口（x 1950，警衛後面）爬出來，顯示一句新文字；警衛事件算是結束（警衛走遠、消失）。

- 數值：躲藏不加數值（和選項「躲進通風管」一樣沒有效果）。
- 女科學家、實驗紀錄、出口都不變；Bad End「編號 07」仍然只有在事件裡選「停下不動」才會發生。

## 3. 作者的決定（都做 A，B 是之後的升級方案）

| # | 問題 | 選項 |
|---|---|---|
| 1 | 警衛怎麼動 | **A（建議）**：站在原地，左右轉身交替（不用新動畫）／B：左右來回走動巡邏（要畫警衛的走路動畫） |
| 2 | 主角躲起來的樣子 | **A（建議）**：主角變暗、半透明（不用新動畫）／B：蹲下的動畫（左右各 2 格，要用 Pixelorama 畫） |
| 3 | 被發現之後 | **A（建議）**：進入原本的警衛事件（抵抗衝動 → 選項）／B：直接 Bad End「編號 07」（比較嚴苛） |
| 4 | 通風管 | **A（建議）**：通風管是避開警衛的捷徑（入口 1450 → 出口 1950）／B：通風管只是一個掩護，還是要等警衛轉身再從他背後溜過去 |

## 3.5 實作時的調整（2026-10-16，MCP 實測）

- **被發現的判定**：不用光錐的幾何角度（手電筒在胸口高度往下照，縱深帶裡的主角只有貼到腳邊才會被照到，那裡已經是警衛事件的觸發範圍），改成「警衛面向主角那一側、主角在畫面上看得到光的地面範圍內（手電筒前方約 266 px，`guard_patrol.gd` 的 `FLOOR_REACH = 0.65`）、不在掩護裡」超過 0.4 秒。
- **位置**：為了讓掩護在光照得到的範圍內，**箱子移到 x 1450、通風管入口移到 x 1545**（原本 1270、1450）；推車旁的躲藏點（x 950）在光外，只是多一個躲的地方。

## 3.6 被發現之後（作者 2026-10-16 再次確認）

維持現在的方式：被發現 → 進入警衛事件（抵抗衝動 → 選項）。另外兩個做法記為之後的升級方案：
- **抓回去**：黑畫面 →「你被拖回實驗室……」→ 回到走廊入口重新躲（潛行壓力高，但被抓的玩家看不到警衛事件，意思也和 Bad End「編號 07」重疊）。
- **折衷**：被發現後，警衛事件裡拿掉「躲進通風管」（只剩撲向警衛、停下不動，兩個都有代價）。

## 4. 新文字（定稿）

| 用途 | 文字 |
|---|---|
| 第一次靠近警衛（畫面下方的提示） | 避開手電筒的光：靠近掩護按 E 躲起來 |
| 掩護的提示 | E　躲起來（推車、箱子）／E　鑽進通風管 |
| 被發現（取代警衛事件原本的開頭） | 手電筒的光停在你身上。「誰在那裡！」槍口跟著對準過來。 |
| 鑽進通風管 | （沿用原本的回應）你擠進狹窄的通風管，屏住呼吸。腳步聲停了一下，又走遠了。 |
| 從通風管爬出來 | 你從通風管另一頭爬出來。走廊盡頭的出口就在眼前。 |

## 6. 資料格式（例子）

```json
"crate": { "type": "hide", "label": "躲起來", "title": "箱子" },
"vent":  { "type": "hide", "label": "鑽進通風管", "title": "通風管",
           "to_x": 1950, "text": "你擠進狹窄的通風管……", "after_text": "你從通風管另一頭爬出來……",
           "done": "guard" },
"guard": { ..., "patrol": { "face_left": 4.0, "face_right": 3.0, "spot_time": 0.4 },
           "variants": [ { "require": { "flags": ["lab.guard.spotted"] }, "text": "手電筒的光停在你身上……" } ] }
```

- 新的互動點類型 `hide`（掩護）；有 `to_x` 的是通風管（移動到另一頭），`done` 指定一起結束的事件。
- 警衛的 `patrol`：轉身的節奏與被發現需要的時間。
- 劇本檢查：`hide` 的欄位、`to_x` 在區域範圍內、`done` 指向存在的互動點、`patrol` 的數字是正數。

## 7. 驗證

- 測試：警衛轉身的節奏；主角在光錐裡超過 0.4 秒 → 被發現 → 警衛事件（被發現的文字、抵抗、選項）；躲在掩護裡光照到不會被發現；鑽進通風管 → 出現在 x 1950、警衛事件結束、可以走到出口；Bad End「編號 07」仍然走得到；劇本檢查抓到寫錯的資料。
