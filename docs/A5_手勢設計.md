# A5-1 手勢：設計與文字（定稿）

> 狀態：**定稿**（Claude 2026-10-14 起草，作者同日定稿：反應文字照草稿、數值用方案 A〔B 當備案〕、按鍵 G、「這裡」改成往地面點兩下）。
> 動畫設計圖：`art/design/a5/gesture_frames.png`（每一格）、`art/design/a5/gesture_preview.gif`（動態）。

## 1. 手勢的意思

劇本裡已經有：主角從前教女兒的手勢「**我——在——這——裡**」（`home.json` 的「比出手勢」、營火故事裡「站在牆邊，比著奇怪的手勢」的靜語者）。
所以主角的手勢就是這三個動作：

| 格 | 意思 | 動作 |
|---|---|---|
| 0 | （抬手） | 手從垂下抬到腰前 |
| 1 | 我 | 手按在自己胸口 |
| 2 | 在 | 手掌張開朝前，舉到下巴前方 |
| 3 | 這裡 | 手往前下方指地面 |
| 4 | 這裡（點） | 手和食指再往下 2px；3、4 交替兩次，像在點地面（作者 2026-10-14） |

節奏：抬手 0.12 秒 → 我 0.45 → 在 0.45 → 這裡 0.2 → 點 0.14 → 這裡 0.14 → 點 0.14 → 這裡 0.2 → 放下 0.12，整套約 2 秒。只畫向右，向左用左右翻轉的畫格（和 A3 的伸手一樣做法）。

## 2. 操作

- 可以走動的時候按 **G** 比出手勢。比的這 2 秒不能移動（像調查時伸手）。對話、選項、轉場中按 G 沒有作用。
- 加一個新的按鍵動作 `gesture`（實體按鍵 G）。
- **怎麼讓玩家知道**：第一次可以走動時（停車場開場文字讀完後），畫面下方淡淡顯示一次「G：比出手勢」，幾秒後消失。
- 聲音：比手勢時有輕微的布料摩擦聲（沿用 A4 的 Kenney 布料聲）。

## 3. 誰會有反應

- 互動點可以加 `gesture` 資料：主角在這個人一定距離內（預設 360 px）比手勢，而且這個人的事件還沒發生，就在比完後顯示一段反應文字（和調查一樣的對話框）。
- **每個人一輪只反應一次**；之後再比，只有動畫。
- 比過手勢會設定旗標「區域.互動點.gesture」，之後的事件可以用現有的 `variants` 依這個旗標換文字（這一版先不用，留給之後）。
- 附近沒有會反應的人時：**第一次**顯示一段獨白，之後只有動畫。

| 地點 | 對象 | 人物動畫 | 反應文字（草稿） |
|---|---|---|---|

| 停車場 | 婦人 | — | 你按住胸口，攤開手掌，再指向地面。婦人僵在原地，盯著你的手。她的嘴唇動了動，像是想問什麼——然後恐懼又回到她臉上。 |

> 女兒在這裡**不舉手回應**：她舉手比回同樣手勢的動畫，留給靠近後的事件（選「比出手勢」）。
> 警衛只是嚇一跳，不會因此觸發 Bad End。

## 4. 數值（作者選 A，B 當備案）

結局 A 需要記憶 ≥ 6、人性 ≥ 3（記憶最多約 9）。手勢如果加數值，結局 A 會變容易。

| 方案 | 內容 | 影響 |
|---|---|---|
| **A（建議）** | 手勢**不加數值**，只有演出和旗標 | 平衡不變，三個結局的條件和現在一樣 |
| B | 少量：女科學家 記憶 +1、妻子 人性 +1、婦人 人性 +1 | 記憶上限變 10，結局 A 稍微容易；要重跑劇本檢查的窮舉 |

## 5. 資料格式（例子）

```json
"woman": {
  "type": "choice", "trigger": "approach", ...,
  "gesture": { "text": "你按住胸口……", "range": 360 }
}
```

- `gesture.text`：反應文字（必要）。`gesture.range`：多遠內有反應（選填，預設 360）。`gesture.effects`：數值（方案 B 才用）。
- 沒有對象時的獨白放在 `story.json` 的 `"gesture_alone"`。
- 劇本檢查：`gesture` 要有 `text`、`range` 要是正數、`effects` 的數值名稱要存在；用故意寫錯的資料測試。
